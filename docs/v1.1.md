# Nötron 1.1

The original website keeps its globe, news cards, voting and voice design. The
country menu now has Gündem and six categories: Siyaset, Finans, Spor, Magazin,
Teknoloji and Eğlence. V2 remains a separate frontend.

## Selection and categories

RSS articles describing the same concrete occurrence are grouped in one event.
The same clustering response supplies its category and specific X search terms;
there is no additional classification/model request. Up to 300 current article
records and 18 event groups are processed in economy mode. Matching existing
event links are supplied to prevent repeated occurrences becoming new cards.

Both a left and a right publisher are required, using the existing `sources`
registry. Center and unknown publishers cannot replace a missing side. Duplicate
URLs and same-publisher/title duplicates do not create a second source. The web
API checks current linked articles independently of stored source counters.
This is a coverage rule, not proof that an event or publisher is unbiased.

The top three eligible events receive the existing independent research and
question review. Other current eligible groups appear as source-backed category
summaries. Those summaries do not invent ballots or expose voting/voice actions
before research is ready. Fewer than three qualified events is a valid result;
one-sided stories are never used to fill the quota.

`Siyaset` includes public affairs, institutions, justice, public safety and
public-service/disaster governance. `Finans` includes economy/business; `Magazin`
covers celebrity/personal-life reporting; `Eğlence` covers arts/music/film/gaming.

## X counts and costs

Create an approved X developer account and app, purchase API credits, and set
`X_BEARER_TOKEN` in the existing Render cron's Environment page. Never commit
the token. Use the Developer Console's spending limit as an additional control.

Only `GET /2/tweets/counts/recent` is used. Queries combine two or three literal
event-specific phrases, `lang:tr` and `-is:retweet`. Counts represent matching
Turkish-language posts, not unique people, all Türkiye residents or article
clicks. No individual post text, user profiles, likes or replies are downloaded.

One request retrieves the last 24 completed hourly buckets. Statistics include
total posts, the last three hours' average posts/hour, the preceding three hours
and their growth ratio. The ranking adds at most 15 points: log-scaled volume
(maximum 10) and recent posting velocity (maximum 5). The contribution ages from
its measurement time and expires after 24 hours. A repeat run cannot refresh
an old measurement. Missing, failed or mismatched measurements never become
fabricated zero counts.

The daily 10:00 Türkiye cron measures up to six eligible candidates, once per
run, with no retry or pagination. At the official 2026-10-18 price of $0.005 per
counts request, this is at most $0.03/day ($0.90 per 30 days) for successful
scheduled runs. A shared database reservation of $0.005 happens before every
attempt, inside the existing $1.50 total daily application envelope (including
the existing compute allowance). Failed/uncertain calls retain their reservation.
Without a token or a working budget ledger, X is skipped and ordinary media and
participant scoring continues. Actual provider billing is authoritative.

Apply the updated function in `backend/daily_budget.sql` before activation; it
adds the $0.005 reservation denomination and retains service-role-only execution.
